Core Modules

Everything to run a construction project

Four focused areas — no bloat, just what a construction company needs day to day.

⬚

Project Management

Create, view, edit, and delete projects. Track name, code, client, location, dates, budget, and status (Planned / Ongoing / Completed).

  • Full CRUD with validation
  • Search, sort & pagination
  • Detail view with BOQ + progress
∑

BOQ Management

Define each project's Bill of Quantities with description, unit, quantity, and unit price. Totals are auto-calculated.

  • Total = Quantity × Unit Price
  • Total BOQ value per project
  • Add / edit / delete items
▦

Materials & Inventory

Maintain a material inventory with current and minimum stock. Record stock-in and stock-out transactions.

  • Stock-out blocked if > available
  • Low-stock warnings
  • Full transaction history
%

Project Progress

Project managers record dated progress entries with a description, percentage, and notes. The latest % shows on the project page.

  • Progress % validation (0–100)
  • Latest % on dashboard
  • Dated progress log
Business Rules

Enforced where it matters

Critical rules are validated on both the client and server, with 16 automated e2e tests guarding them.

01

BOQ total auto-calc

total = quantity × unitPrice computed on create and re-computed on update.

02

No negative stock

Stock-out quantity exceeding available stock returns 400 Bad Request.

03

Low-stock warnings

Material is flagged when currentStock ≤ minimumStock, surfaced on the dashboard.

04

Latest progress

Project detail & dashboard reflect the most recent progress percentage recorded.

Quick Start

Up and running in minutes

1
git clone https://github.com/Lib1221/COTM.git
cd COTM && pnpm install
2
pnpm docker:up        # postgres + api + web
pnpm db:migrate      # create schema
pnpm db:seed         # sample data
3
# web  → http://localhost:3000
# api  → http://localhost:4000/api
# docs → http://localhost:4000/api/docs
